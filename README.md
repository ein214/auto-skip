# AutoSkip

개인 Android 폰에서 쓰는 **광고 종료 도우미**입니다. 보상형 광고(예: 뮤니버스 충전소의 "영상보고 ⭐ 5 받기", TIN의 "동영상 광고 시청하기")를 **사용자가 직접 시작한 뒤**, 광고가 끝나면 나타나는 Skip / X / `»` 버튼을 대신 눌러 원래 앱으로 돌려보냅니다.

> 개인 기기에 직접 설치하는 로컬 APK입니다. 스토어 배포용이 아닙니다.

## 기획 의도

하루에 받을 수 있는 광고 보상은 정해져 있고, 광고는 직접 봅니다. 그런데 광고가 끝날 때마다 해야 하는 손동작이 꽤 번거롭습니다.

- 광고마다 위치와 모양이 다른 작은 X를 찾아 누르기
- X가 잠깐 나왔다 사라지는 걸 기다리기
- 스토어로 넘어간 뒤 뒤로가기를 두 번 눌러 광고로 돌아오기
- 쿨타임(예: 780초)이 끝났는지 앱을 열어 계속 확인하기

AutoSkip은 이 반복 동작만 대신합니다. **광고를 보는 사람이 그 자리에 있다**는 전제는 그대로 둡니다.

### 하지 않는 것 (의도적으로 제외)

| 하지 않는 것 | 이유 |
|---|---|
| 광고 시작 버튼 자동 클릭, 반복 시청 루프 | 사람이 보지 않는 광고 노출은 광고 업계에서 무효 트래픽으로 분류됩니다. 앱 약관 위반이나 계정 제재로 이어질 수 있습니다. |
| `Google Play` / `Install` / `받기` 등 스토어 이동 버튼 자동 클릭 | 광고 클릭으로 집계되어 광고주에게 청구됩니다. 자동으로 누르면 가짜 클릭이 됩니다. |
| 쿨타임 우회, 보상 자동 적립 | 위와 같은 이유입니다. |
| 스토어 화면 안의 버튼(설치 등) 클릭 | 사용자 의사와 무관한 설치를 막기 위해서입니다. |

## 광고 한 번의 흐름

| 단계 | 누가 |
|---|---|
| 광고 시작 | 사용자 |
| 스토어 이동 버튼 탭 (스토어에 다녀와야 X가 나오는 광고만) | 사용자. 버튼이 뜨면 AutoSkip이 주황 테두리와 짧은 진동으로 알려 줍니다 |
| Play 스토어에서 광고로 돌아오기 (뒤로가기 최대 2회) | AutoSkip |
| `»` 건너뛰기, Skip / Close / X 닫기 | AutoSkip |
| 원래 앱 화면으로 돌아왔는지 확인 | AutoSkip |
| 쿨타임이 끝나면 알림 (소리 + 짧은 진동) | AutoSkip |

## 주요 기능

- **허용 앱에서만 동작:** 사용자가 체크한 앱에서만 화면을 읽습니다. 스토어, 설정, 시스템 화면은 선택할 수 없습니다.
- **광고 화면 판별:** 허용 앱 자체 코드가 아닌 외부 라이브러리 화면(광고 SDK의 전체 화면 Activity)을 광고로 봅니다. 알려진 SDK 목록에 없어도 동작합니다. 로그인, 결제, 인앱 브라우저 라이브러리는 제외하고, 결제·비밀번호 같은 문구가 보이면 멈춥니다.
- **종료 버튼 찾기:**
  1. 접근성 노드에서 찾습니다: `Skip`, `Close`, `건너뛰기`, `닫기`, `X`, view id의 `close`/`skip` 등. 비활성 버튼이나 카운트다운 중인 버튼("5초 후 건너뛰기")은 누르지 않습니다.
  2. 노드가 없는 광고(WebView에 그림으로만 그린 X)는 화면 **위쪽 양 모서리**만 캡처해 X 또는 `»` 모양을 찾습니다. 0.5초 뒤 다시 캡처해 같은 자리에 있을 때만 탭합니다.
- **안전장치:**
  - 클릭 직전에 다시 탐색하고, 광고 1회당 클릭 횟수를 제한합니다(닫기 4회, `»` 4회).
  - 외부 앱으로 넘어가 있는 동안에는 아무것도 누르지 않습니다.
  - 확인할 수 없는 화면이 나오면 `UNKNOWN`으로 정지합니다.
- **긴급 중지:** 앱의 스위치나 빠른 설정 타일로 즉시 끌 수 있습니다.

## 구조

기획서 [auto-skip.md](auto-skip.md)의 역할 분리를 따릅니다.

```text
app/src/main/java/com/personal/autoskip/
  accessibility/   접근성 서비스(이벤트 수신, 캡처, 제스처), 노드 탐색, 클릭 실행, 스토어 버튼 강조 오버레이
  detection/       순수 Kotlin 판정 로직: 광고 화면, 종료 버튼(노드/이미지), 쿨타임 문구
  automation/      상태 머신(순수 전이 함수), 세션 컨트롤러(타이머·부수효과), 세션 로그, 쿨타임 알람
  settings/        DataStore(ON/OFF, 허용 앱, 통계)
  ui/              설정 화면(Compose)
mockhost/          테스트용 모의 호스트 앱과 모의 광고 Activity
```

상태 머신은 기획서 §2를 따릅니다: `IDLE → AD_DETECTED → AD_PLAYING → END_CARD → EXTERNAL_STORE → RETURNED_TO_AD → CLOSE_READY → AUTO_CLOSE → VERIFY_HOST → IDLE`. 실기기 테스트를 거치며 바꾼 점은 아래 "기획서 v0.2 이후 결정"에 정리했습니다.

## 개인정보와 권한

- **인터넷 권한이 없습니다.** 화면 텍스트와 이미지는 기기 밖으로 나가지 않습니다.
- 화면 캡처는 광고 화면에서만, 위쪽 16% 영역만 메모리에서 처리하고 저장하지 않습니다.
- 허용 목록 밖 앱은 패키지 이름만 보고(스토어로 넘어갔는지 판단하는 용도), 화면 내용은 읽지 않습니다.
- 광고 화면의 노드를 logcat에 남기는 진단 로그는 기본 꺼짐입니다. `./gradlew assembleDebug -PautoskipDiag=true`로 빌드할 때만 켜집니다.

| 권한 | 용도 |
|---|---|
| 접근성 서비스 (사용자가 직접 켬) | 화면 노드 읽기, 버튼 클릭, 위쪽 모서리 캡처, X 위치 탭, 뒤로가기 |
| `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` | 삼성 기기가 조용한 광고 화면에서 서비스를 동결해 재확인이 멈추는 것을 막기 위해 배터리 제한 해제를 요청 |
| `POST_NOTIFICATIONS`, `USE_EXACT_ALARM` | 쿨타임 종료 알림 |
| `VIBRATE` | 스토어 이동 버튼이 나타났을 때 짧은 진동 |

## 빌드와 설치

준비물: JDK 17, Android SDK (platform 35, build-tools 35), adb

```bash
# JDK 17 지정 (둘 중 하나)
export JAVA_HOME=/path/to/jdk-17
# 또는 ~/.gradle/gradle.properties 에 org.gradle.java.home=/path/to/jdk-17

echo "sdk.dir=$HOME/Library/Android/sdk" > local.properties
./gradlew :app:testDebugUnitTest assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb install -r mockhost/build/outputs/apk/debug/mockhost-debug.apk   # 테스트용 (선택)
```

설치 후 AutoSkip 앱에서 다음을 순서대로 켭니다.

1. **접근성 설정 열기** → 설치된 앱 → AutoSkip → 사용 → 허용
   - Android 13 이상에서 스위치가 막혀 있으면: 앱 정보 → ⋮ → 제한된 설정 허용
2. **자동 종료 사용** 스위치
3. **알림 허용** (쿨타임 알림용)
4. **배터리 제한 해제** (삼성 기기에서 특히 필요)
5. **허용 앱** 체크

## 테스트

- **단위 테스트** `./gradlew :app:testDebugUnitTest`
  - 상태 머신, 종료 버튼 판정, 광고 화면 판정, 쿨타임 문구 해석을 검증합니다.
  - 이미지 판별은 실기기에서 캡처한 실제 광고 화면으로 검증합니다. 위쪽 400px만 잘라서 저장했습니다.
- **모의 광고 (`mockhost`)**

  | 유형 | 재현하는 상황 |
  |---|---|
  | A | 비활성 "N초 후 건너뛰기" → 활성 "건너뛰기" |
  | A2 | 영상 끝나고 7초 뒤 Skip 등장 (지연 종료) |
  | B | 엔드카드 → 사용자가 스토어 이동 → 복귀 4초 후 X |
  | C | Skip → 같은 화면에서 엔드카드 → X (다단계) |
  | D | 노드 없이 그림으로만 그린 X |
  | 일반 팝업 / 공지 화면 | 광고가 아닌 화면의 X는 누르지 않아야 함 |

## 실기기에서 확인한 것 (Galaxy S23 Ultra, Android 16)

| 앱 / 광고 SDK | 결과 |
|---|---|
| 뮤니버스 / AppLovin | X가 노드로 노출되지 않음 → 이미지로 찾아 닫음. 스토어 왕복 후 자동 복귀 |
| 뮤니버스 / BidMachine | `»` → `»` → 회색 원 안의 X. 이미지로 처리 |
| 뮤니버스 / Moloco | `▶|` 버튼이 `Skip` 노드로 노출됨 |
| TIN / Google 광고 | `광고 3/3` 연속 광고. 왼쪽 위 `Close` 노드. 쿨타임(`695초`) 알림 동작 |

## 알려진 한계

- **X 모양:** 지금은 흔한 X 두 가지(어두운 배경의 흰 X, 원 안의 X)와 `»`만 알아봅니다. 처음 보는 모양은 스크린샷을 모아 판별 기준을 추가해야 합니다.
- **화면을 탭해야 나타나는 X:** AutoSkip이 대신 탭하지 않습니다. 광고 본문을 잘못 누르면 스토어로 넘어갈 수 있기 때문입니다.
- **광고가 아닌 외부 화면:** 허용 앱 안의 외부 라이브러리 화면(오퍼월 등)을 광고로 착각할 수 있습니다. 이상하게 닫히는 화면이 있으면 제외 목록에 추가해야 합니다.
- **화면 확인 도구 사용 중:** `uiautomator dump`를 실행하는 동안에는 Android가 접근성 서비스를 잠시 해제합니다.

## 기획서 v0.2 이후 결정

실기기 테스트를 거치며 [auto-skip.md](auto-skip.md)에서 바꾼 점입니다. 각 결정은 코드 주석에도 표시했습니다.

1. **다단계 광고:** Skip을 누른 뒤에도 같은 광고 화면이면 종료 버튼을 다시 찾습니다(클릭 상한 안에서).
2. **이미지로 X / `»` 찾기 (P2):** 접근성 서비스 스크린샷을 써서 MediaProjection 동의 없이 처리합니다.
3. **스토어 자동 복귀:** 사용자가 광고에서 Play 스토어로 이동했을 때만 뒤로가기를 최대 2회 누릅니다(기획서의 "뒤로가기 자동 실행 제외"를 좁게 변경).
4. **광고 판별 규칙:** SDK 목록 대신 "허용 앱 밖의 라이브러리 화면"을 광고로 봅니다.
5. **`UNKNOWN` 해제:** 호스트 화면이 확인되면 `UNKNOWN`에서 `IDLE`로 돌아갑니다.
6. **대기 시간:** 사용자가 스토어에 다녀오는 단계가 있어 상태 제한시간을 10분으로 늘렸습니다.
7. **편의 기능:** 스토어 이동 버튼 강조 표시와 쿨타임 종료 알림을 추가했습니다(누르는 것은 사용자).

## 주의

개인 학습과 사용 목적의 프로젝트입니다. 접근성 서비스는 화면 내용을 읽고 조작할 수 있는 강한 권한이므로 신뢰하는 기기에만 설치하세요. 각 앱의 이용약관은 사용자가 직접 확인해야 합니다.
